# Заметки по Этапу 1: Git

## Освоено
- Базовые команды: init, clone, add, commit, push, pull, status
- Ветвление: создание, переключение, слияние (merge)
- Решение конфликтов слияния
- Pull Request (этот самый PR)

## Полезные команды
- git log --oneline --graph --all — визуализация истории
- git checkout -b <name> — создание и переключение ветки
- git branch -M main — переименование ветки
- git config pull.rebase false — настройка стратегии merge
